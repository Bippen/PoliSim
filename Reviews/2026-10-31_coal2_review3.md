## Possessive outputs

`EnglishText.Possessive(name, upper: false, abbreviation: true)` returns `""` for a null or empty name. For any other name it returns `name + "'s"`: the s-ending rule (apostrophe only) is skipped when `abbreviation` is true, and `upper` false picks a lower-case `'s`. The new output therefore equals the old `name + "'s"` for every non-empty key. Without `abbreviation: true` the keys ending in s/S would have changed, but the call passes true.
