3. (Q2) Edges — CORRECT. The diagnostic's Point() (eve vs day) exercises exactly this. Severity: none.

4. (Q3) CampaignCalendar in the static initializer — SAFE. CampaignCalendar (Assets/Scripts/Elections/CampaignClock.cs:69–100) is a readonly struct with only consts, an instance ctor and computed properties (Sweden2026 is a getter, no static storage), so constructing it touches no other type's static state. Inside DeclaredRedLines, `Open` and `D` are declared textually before `SwedenTimeline` (required, since they are used by it), and the class has no static ctor. Value: 2022-09-11 − 8×7 d = 2022-07-17, as the caller states. One dependency worth noting (LOW): the From date rides `DefaultCampaignWeeks`, a strikeable [AUTHORED-DRAFT] constant; if it changes, the fact's From moves silently and the 2022-09-11 equality still passes. The comment says "the model's window", so this is disclosed, not hidden.

6. (Q4) Duplicates — NONE POSSIBLE. ForDate adds pair lines only for FactKind.PairLine facts; S and M have only Candidacy facts, so a pair can never get both a candidacy line and a pair line. C↔SD: fact #1 Until 2025-11-13 (exclusive) and fact #2 From 2025-11-13 (inclusive) — on 2025-11-13 exactly one stands. The diagnostic's overlap test `f.From >= b || f.Until <= a` (line 89) is the correct half-open disjointness test and keys on Kind+Party+Other, so it would catch a regression. Severity: none.

7. (Q5) Overloads — UNAMBIGUOUS, vintage path unchanged. Third-parameter types are ElectionVintage (enum) vs IReadOnlyList<(string,string,string)>; the two call sites pass a typed enum variable and the typed return of CandidaciesAt, never null/literal, so overload resolution cannot tie. The old overload's body is untouched. Quality nit (LOW): the two bodies are byte-identical loops; the old could delegate `AddCandidacyLines(lines, parties, Candidacies(CountryId.Sweden, vintage))`. Not a defect.

8. (Q6) Index assumptions in the diagnostic (DeclarationDatesDiagnostic.cs:73, 75) — HOLD BUT BY ARRAY ORDER ONLY. CandidaciesAt iterates SwedenTimeline in declaration order; the two S facts precede the two M facts, so with exactly two standing [0]=S and [1]=M on all dates tested. There is no contract guaranteeing that order (a reordering of the array would flip the assertions; a single standing candidacy would throw IndexOutOfRange, caught by the try/catch and counted as a failure but with the THREW text instead of the check's message). LOW: robust form would find by Abbrev. The bases asserted are distinct (2022 M basis contains "2022-03-26" and not "[MSD-P1]"; 2022 S basis contains "2022-08-04", "[S-P1]" but not "[S-P2]"), so the Contains checks are discriminating, not tautological.
