## Verdict

The claim **holds for the possessive routing**. I found no routed site whose output changes for any party key, and none whose output changes for the data the game carries today. I found no high-severity defect.

There is one missed "1 SEAT" site on the election night, which is the screen this branch says it covers. There is one latent break in the unnamed-candidate label contract. MetaTextCheck's new pass works as written, but its blind spots are wider than its doc says.

## Findings, ranked

### M1. The election night's reference slip still prints "1 SEATS"
- **Where:** `Assets/Scripts/UI/ElectionNightScreen.cs:1173`:
  `string.Format(CultureInfo.InvariantCulture, "PLAYED {0} SEATS · THE REAL RESULT {1}", played, real)`
- **Failure:** the played-against-real panel builds one slip per party. A party that wins one seat reads "PLAYED 1 SEATS · THE REAL RESULT 1". Germany's SSW is that party, and the code already knows it: line 443 hand-builds " seat" for "the SSW's row".
- **Why it matters:** J8's "1 SEAT" is filed against this screen, and the branch claims the night's rows are done. This slip is the one left over.
- **Fix:** `"PLAYED " + UiFormat.Seats(played).ToUpperInvariant() + " · THE REAL RESULT " + real`. Also route line 443's hand-built ternary through `UiFormat.Seats`, so that one helper owns the noun (that part is cosmetic).

### L1. The unnamed-candidate label contract is broken for a party name ending in s (latent)
- **Where:**
  - `Assets/Scripts/Elections/UsTermLimit.cs:144`: `UnnamedNominee` now goes through `Possessive(party.Name)`.
  - `Assets/Scripts/Elections/UsTermLimit.cs:148`: `UnnamedRunningMate`, the same.
  - A party whose name ends in s now yields `"<Name>' candidate (yyyy)"`.
- **The readers that did not follow:**
  - `Assets/Scripts/Data/OwnNominee.cs:127` was widened to also refuse `"' candidate"`.
  - `Assets/Scripts/Elections/WorldClock.cs:296` (`SurnameOf`) still tests only `name.Contains("'s candidate")`.
  - `Assets/Scripts/UI/GameController.ParliamentRows.cs:633` (`unnamed`) also tests only `"'s candidate"`.
  - `UnnamedRunningMate`'s doc comment promises that `WorldClock.SurnameOf` keeps the label whole. For such a name that is no longer true: `SurnameOf` returns the last word, "(2028)".
- **Reachability today:** none. The labels are built only from `PartySystems.For(CountryId.USA)`, which holds "Republican Party" and "Democratic Party". Poland's form (`PresidentialElection.cs:394`) passes `abbreviation: true`, so it always reads 's.
- **Failure scenario:** a US roster party whose name ends in s, such as "Libertarians", gets its surname row printed as "(2028)". The guard and the reader then disagree.
- **Fix:** add one predicate, for example `UsTermLimit.IsUnnamedLabel(string)`, that matches both forms, and use it in `OwnNominee`, `SurnameOf` and `ParliamentRows`. Alternatively, pin the label to a fixed form that never takes the bare apostrophe.

### L2. MetaTextCheck's possessive pass has false negatives its doc does not state
In `Assets/Editor/MetaTextCheck.cs`, `HandBuiltPossessives` and `Literals`:
1. **Literals nested inside an interpolation hole are never examined.** `Literals` copies a hole's raw text and moves past it, and `HolePossessive` needs `}'s`. So `$"{(c ? a : key + "'s")} frames"` is missed. The base tree held exactly this form at `SimulationManager.cs:1381` (`alternative.TabledBy + "'s"` inside a hole). It escaped only because that line is also a `Debug.Log` line.
2. **The exemption covers the whole line.** `DiagnosticLine` exempts the entire source line, so a player-visible `Breaks.Add($"{x}'s ...")` that shares its line with a `Debug.Log` escapes. This codebase writes in exactly that one-line style, for example `SimulationManager.cs:1376`. In addition, `\.Log\(` also matches `Math.Log(` and `Mathf.Log(`.
3. **Only a preceding `+` counts as concatenation.** These forms are all missed: `.Append("'s")`, `string.Concat(x, "'s")`, `s += "'s"`, a ternary arm `(c ? "'s" : "")`, and the bare apostrophe built by hand (`name + "' "`).
4. **Escaped apostrophes are mis-decoded.** An escaped `"’s"` in source is decoded by `Literals` as "u2019s" (it drops the backslash and keeps the next character), so the curly form written as an escape is missed. The fourth planted tooth passes only because the C# compiler turns that escape into the real character inside MetaTextCheck's own string.
5. **The teeth plant none of the forms above.** They also do not exercise `AllowPossessive` or the `Testing/` exclusion in the file walk.

A static sweep of every runtime file for `}'s`, `+ "'s`, a literal that opens with 's, and `’s` found **no hand-built possessive the pass misses today**. These are guard gaps, not live defects.

- **Fix:**
  - Scan nested literals inside holes.
  - Narrow the exemption to the literal's enclosing call, not its line.
  - Treat `(`, `,`, `?`, `:` and `+=` before an 's-leading literal as concatenation when the token before them is an expression.
  - Decode `\uXXXX`.
  - Plant one tooth per class.

### L3. MetaTextCheck's possessive allow-list and false positives
- **The allow-list matches the whole line.** `AllowPossessive` matches a substring of the line, so a second hand-built possessive added to any of the five allowed lines is silently allowed. The five lines are `PensionAgeStatute.cs` THE KNOB, `EnergyConnectionQueue.cs` VOLUME, `PresidentialElection.cs:319`, `UsCongressElection.cs:492` and `UsPresidentialElection.cs:447`. Match on the literal, or carry an expected count per line.
- **False positives (latent; none today):**
  - A multi-line `Debug.Log(` or `throw` whose literal sits on a continuation line. `lineText` is the literal's own line, so the exemption is lost.
  - Escaped braces, `$"{{x}}'s"`.
  - A literal joined to a literal, `"the government" + "'s frames"`.

### L4. The runtime now depends on the `PoliSim.UI` namespace (layering)
- **Where:** `Data/OwnNominee.cs` (indirectly), `Elections/*`, `Simulation/SimulationManager*.cs` now call `PoliSim.UI.UiFormat`. No runtime file under Simulation, Elections or Data referenced `PoliSim.UI` at the base.
- **Safe today:**
  - There is no `.asmdef`; everything compiles into Assembly-CSharp, and the Editor's `using PoliSim.UI;` resolves.
  - `UiFormat` touches only `System` and `System.Globalization`. Its static state is one tuple array plus consts, with no Unity types, fonts or `PoliSimTheme`. Static init is safe in batchmode and with no graphics.
- **Risk:** the first asmdef split breaks the build. Some may also read it as "the model reads the UI".
- **Fix (optional):** move `Possessive` and `Seats` into a neutral static class, for example `PoliSim.Text`, and keep thin forwarders in `UiFormat`.

### L5. A null or empty name now renders a bare noun
- **Behaviour:** `Possessive(null|"")` returns its input, so a null key now renders " candidate", " alternative" or " cabinet". The hand-built form rendered "'s candidate".
- **Sites where the value could be null:**
  - `ConfidenceProcedure.Title` (`Mover`)
  - `SimulationManager.Sejm.cs` (`g.PmParty`, `f.PmParty`)
  - `SimulationManager.cs` (`fallen.PmParty`, `g.PmParty`, `alternative.TabledBy`)
- **Severity:** both forms are garbage, neither throws, and none is reachable in normal play. Noted for completeness only.
