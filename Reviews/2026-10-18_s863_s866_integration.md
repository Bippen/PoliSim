## What the first run on this tree found, and the fixes (no game code changed)

The branches were built against the compile gate alone, so `n863` was the first Unity run of their new diagnostics. Three checks were red. Each cause is below.

- **The CBO letter, damaged in transit.** The patch carried `raw/lapse/wayback_20251029174958_cbo_61823-Shutdown.pdf` as text. Git for Windows maps `*.pdf` to the `astextplain` diff driver, so the patch held a text dump of the PDF instead of its bytes, and 20,399 bytes landed where 363,338 belong. The digest check caught it. The file is restored byte for byte from `wave/us22b` (blob `53a316fc`, SHA-256 `6bcce194...`, the digest in `raw/lapse/SHA256SUMS.txt`). Every other non-text file in the batch was checked against its branch's blob, and none differs.
- **`UsDocketDiagnostic` (c) and (e): the budget refused.** It introduced its budget with `IntroduceBudgetBill` on 2025-02-24, outside the budget window. Since AF-9 (§859, ruling q9) the manager refuses that ("THE BUDGET PROCESS IS NOT OPEN"), so the budget's two acts never reached the docket. The harness now uses `BudgetBillHarness.Introduce`, which AF-9 provides for this case: it plants the window and takes the plant back on a refusal.
- **`UsBudgetProcedureDiagnostic` (c) W2: the division log's cap.** W2 writes about 34 divisions, and `DivisionLog.MaxEntries` keeps the newest 24. The harness read the log once, after the run, so the appropriation of 2025-08-19, the eve's resolution and the first lapse votes were evicted. `RunW2` now collects the divisions at the end of each day.
- **`UsBudgetProcedureDiagnostic` (i): no lapse at the cut.** The save case drew the withholder's senators by the play key, and that key (seed 777) carries cloture on 2025-10-10, so on the cut's day of 2025-10-15 no lapse was left to save. The case now plants the draw at index 0, as W2's held run does.
- **`UsBudgetProcedureDiagnostic` (a): a float literal.** `UsLapse.LevelPairPercent` is `0.24f`, which is stored as 0.2399999946, so `QuarterOutputBillions` is 7500.00017. The check's tolerance of 1e-6 is now 1e-3. `UsLapse.cs` is unchanged: the error is about 2e-8 of the quarter, far inside CBO's own rounding.
- **`ReviewLedgerCheck`: a stale grandfathered row.** `ProgramBill.cs` has moved on from the state the guard found, and its new state has its own `reviewed` row (US-21b's review). The old row is removed, and `GrandfatheredCeiling` goes from 12 to 11.

After the fixes, `n863b` (`UsDocketDiagnostic`, `UsBudgetProcedureDiagnostic`, `CommentClaimCheck`, `MetaTextCheck`, `DeadStateCheck`) is 5 of 5 clean. W2 now reads the record's shape:
