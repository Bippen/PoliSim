- **"no count on":** the only other hit is `PreStartRecordDiagnostic.cs` ("no count on disk to compare with"), which is unrelated and does not read logs.
- **"the count of":** read from the log in only two places, and both are still right:
  - `UsPresidentialElectionDiagnostic`'s listener collects every condition that starts with `"PRESIDENTIAL: USA"`. It then counts the logged lines that start with `"PRESIDENTIAL: USA - the count of "` and requires exactly one. The old failure text started with that prefix, so a failure would have been counted as a count; the new text is not. A failed count still fails check (c) through `played != null`, so the diagnostic loses no detection power.

They are "no poll", the NaN-factor line, "no candidate has support in the poll", "chooses no president by electors", "the count needs both nominees, ...", "the catalog holds no presidential election before YYYY ...", "the country carries no list of contests" and "not a polling day ...".
