### MEDIUM 1: TakeOffice's new guard reads state that a load discards (load and continuous runs diverge on a money path)

**Where.** `Assets/Scripts/Simulation/SimulationManager.cs:4059`:
`if (!IsIncomingGovernmentBudgetWindow(country.Id)) { ResetArrivalBudgetWindow(country.Id); }`

**Why it breaks.**
- `IsIncomingGovernmentBudgetWindow` (977-981) needs `_incomingBudgetWindowOpenNow` (972).
- That set is not in the save. `CaptureSaveState` (2500-2510) saves only `PendingBudgetProcess` and `IncomingBudgetWindowUsed`.
- `RestoreSaveState` clears it (4706) and nothing puts it back. The only writer is `TryOpenBudgetProcess` (2460).
- So after any load the guard is false while an arrival window stands.

**Failure scenario.**
- Setup:
  - A DEM player.
  - A decided DEM contest, from US-8's count or (c)'s planted one.
  - The arrival window open and unused, with the MM-2 setting "THE BUDGET WINDOW" off. The window holds the clock only while that setting is on: `GameController.cs:1401`, `2544`.
- Continuous run: on 20 Jan 2025 the guard is true and the used flag stays. One arrival window in all.
- The same game saved on 10 Jan and loaded: the guard is false and the used flag is reset. When the player tables the budget and its bill resolves, `TryOpenBudgetProcess` (2457-2461) opens a second arrival window.
- That is one more budget window than the continuous run gets. It is exactly the case commit 6686f04c was written to prevent.
- PresidencyDiagnostic (c) proves only the continuous run, because its save is cut after the oath.
- The no-party record oath (low 3) diverges the same way.

**Fix.**
- Carry `_incomingBudgetWindowOpenNow` in `SimulationPendingState` and restore it in `RestoreSaveState`. The field is additive, and this item is already stepping the format to 39.
- This also fixes an older mislabel: today a loaded arrival window reads as the annual window.
- Add a case (c'): cut (c)'s world on 19 Jan, adopt it through `RestoreFromSave`, step to the 20th. Assert that `IncomingBudgetWindowUsed` still holds USA and that `IsIncomingGovernmentBudgetWindow` is true.
